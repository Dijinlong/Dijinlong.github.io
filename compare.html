Six checks before you switch to another LLM API reseller

Published 2026-11-21 · LONG AI

Every reseller quotes a discount. Almost none of them tell you what breaks first under real traffic. These six checks take an afternoon, and each one has a failure mode we have actually seen in production behind 51 upstream sellers.

1. Stream shape, not just status code

Send a streaming request and look at the chunks themselves: is delta.content populated, does finish_reason arrive once, does the stream end cleanly. Channels that pass a non-streaming smoke test routinely break here, because the adapter was written for the buffered path.

2. Tool calls from a model that claims support

"Supports function calling" is a claim on a price page. Test it: two tools in one turn, then check that tool_calls[].function.arguments is valid JSON in every fragment. Silent truncation of the arguments block is a common defect and it only surfaces on the second tool.

3. Usage accounting on the final chunk

If usage is missing from stream responses, you are estimating tokens — and estimates drift against the bill in a direction that is never favourable. Compare reported tokens with what your own tokeniser computes for three prompts before trusting the numbers.

4. What happens on failure

Fail the upstream on purpose — wrong key, unsupported parameter, oversized context — and watch what comes back. A reseller that hides upstream errors behind a generic 500 makes debugging impossible. You want the upstream status and body preserved in a typed error, plus transparent failover to the next channel.

5. Is the price list a table or a screenshot

A per-model ratio list that is generated from the same data the settlement engine reads can be trusted. A marketing page that says "up to 90% off" cannot. Check whether the discount is per model, whether input and output are priced separately, and whether the list updates when the upstream price moves.

6. A status board you can watch

Latency and availability per channel, updated continuously, is the cheapest way to tell whether a problem is yours or theirs. If there is no public status page, you will discover outages from your own users instead.

Run the checks

LONG AI runs 103 models across 51 upstream sellers behind one OpenAI-compatible endpoint, with automatic failover and a public status board — the six checks above are the same suite we run before a channel enters the primary lane.
